# Heartlog Legal Documents Website

This repository contains the legal documents website for Heartlog, including Privacy Policy and Terms of Service.

## Files

- `index.html` - Landing page with links to legal documents
- `privacy-policy.html` - Privacy Policy
- `terms-of-service.html` - Terms of Service
- `styles.css` - Styling for all pages

## Deployment via GitHub Pages

This repository is set up for GitHub Pages deployment.

### Enable GitHub Pages

1. Go to repository Settings
2. Navigate to "Pages" in the left sidebar
3. Under "Source":
   - Branch: Select **"main"** (or "master")
   - Folder: Select **"/ (root)"**
4. Click "Save"
5. Wait 2-3 minutes for deployment

### Your Live URLs

Once deployed, your legal documents will be available at:

- **Homepage**: `https://YOUR_USERNAME.github.io/heartlog-public-pages/`
- **Privacy Policy**: `https://YOUR_USERNAME.github.io/heartlog-public-pages/privacy-policy.html`
- **Terms of Service**: `https://YOUR_USERNAME.github.io/heartlog-public-pages/terms-of-service.html`

Replace `YOUR_USERNAME` with your GitHub username.

## For App Store Connect

Use these URLs in App Store Connect:

- **Privacy Policy URL**: The privacy-policy.html URL from above
- **Terms of Service URL**: The terms-of-service.html URL from above

## Updating Content

To update the policies:

1. Edit the HTML files locally
2. Commit and push changes:
   ```bash
   git add .
   git commit -m "Update privacy policy"
   git push
   ```
3. Changes will be live in a few minutes

## Local Development

To preview locally, simply open any HTML file in your browser.
